Модуль 1: Основы Git

Базовые команды инициализации, индексации и коммитов

Инициализация
Превращает текущую папку в Git-репозиторий.
git init
Статус и Индекс
Проверить измененные файлы и добавить их в индекс.
git add .
Создание коммита
Фиксация точки сохранения с комментарием.
git commit -m "feat: msg"

Модуль 2: Работа с Ветками & SSH

Изолированная разработка, слияния и синхронизация с GitHub

Создать ветку
Создание новой фиче-ветки и переключение на нее.
git switch -c feature/name
Отправка на GitHub
Загрузка новой ветки в удаленный репозиторий.
git push -u origin branch
Скачать обновления
Синхронизация локальной ветки с изменениями на сервере.
git pull
