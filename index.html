☁️ DevOps Git Ultimate Handbook

1. Первоначальная настройка (git config)

git config --global user.name "Имя" Задать имя автора коммитов во всех репозиториях.
git config --global user.email "mail@ex.com" Задать email автора для привязки к аккаунту GitHub/GitLab.
git config --global init.defaultBranch main Сделать main названием главной ветки по умолчанию.
git config -l Посмотреть список всех активных настроек Git.

2. Инициализация и скачивание (init & clone)

git init Превратить текущую папку на ПК в Git-репозиторий.
git clone <url> Скачать существующий репозиторий с сервера на ПК.
git clone -b <branch> <url> Скачать только одну конкретную ветку из репозитория.

3. Ежедневный рабочий цикл (status, add, commit)

git status Проверить статус файлов (изменены, добавлены, отслеживаются).
git add . Добавить ВСЕ измененные файлы и папки в индекс (Staging).
git commit -m "feat: text" Зафиксировать точку сохранения с понятным описанием.
git commit --amend -m "new msg" Перезаписать самый последний коммит (исправить текст или докинуть файлы).

4. Работа с ветками (branch, switch)

git branch -a Показать полный список веток (локальные + на сервере).
git switch -c feature/name Создать новую фиче-ветку и сразу переключиться на нее.
git switch main Переключиться на существующую ветку (например, main).
git branch -d feature/name Безопасно удалить локальную ветку, если она уже слита.

5. Слияние, история и перенос (merge, rebase, log)

git log --oneline --graph Красивое компактное дерево истории коммитов в терминале.
git merge feature/name Слить указанную ветку в текущую локальную ветку.
git rebase -i HEAD~3 Интерактивное меню для перестановки, редактирования и склейки коммитов.
git cherry-pick <hash> Скопировать один конкретный коммит из другой ветки к себе.

6. Синхронизация с сервером (push, pull, remote)

git push -u origin branch Впервые выгрузить созданную локальную ветку на GitHub.
git pull Скачать свежие изменения с GitHub и сразу слить с локальным кодом.
git push --force-with-lease Безопасный принудительный пуш (используется после rebase или amend).

7. Отмена и спрятывание изменений (restore, reset, stash)

git restore <file> Отменить незакоммиченные изменения в конкретном файле.
git reset --soft HEAD~1 Отменить последний коммит, но СОХРАНИТЬ все изменения в файлах.
git stash Спрятать несохраненные правки во «временный карман».
git stash pop Достать спрятанные правки из «кармана» обратно в код.

8. Аварийная хирургия и поиск (reflog, blame)

git reflog Главная машина времени: журнал вообще ВСЕХ действий для восстановления удаленного.
git blame <file> Показать построчно, кто и когда редактировал каждый фрагмент файла.
