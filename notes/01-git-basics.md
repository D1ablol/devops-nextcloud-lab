# 📌 Конспект 1: Основы Git & GitHub

## 1. Главные понятия
- **Репозиторий:** Папка с памятью (хранит историю изменений).
- **Индекс (Staging):** Промежуточная зона перед сохранением (`git add`).
- **Коммит:** Точка сохранения / снимок состояния кода (`git commit`).

## 2. Шпаргалка по командам

| Команда | Описание |
| :--- | :--- |
| `git init` | Инициализировать репозиторий |
| `git status` | Проверить состояние файлов |
| `git add .` | Добавить все файлы в индекс |
| `git commit -m "..."` | Зафиксировать коммит |
| `git log` | Посмотреть историю |
